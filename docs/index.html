Aquagem pump compatibility

The integration is built around protocol signatures rather than only commercial model names. Two Aquagem pump families are currently validated on real hardware.

Validated hardwareProtocolRS485ControlStatus
iSaver Power 1100Proprietary C3 / D01200-8-N-11200–2900 rpm · OFF=1✅ Validated
DM15 / INVERsilenceModbus RTU 03 / 109600-8-N-130–100% · OFF=0✅ Validated
Your Aquagem model is not listed?Automatic detection checks protocol structure, CRC and coherent register values. Other Aquagem pumps using the same validated register layout may be compatible even when their commercial model name has not yet been field-tested.

One Home Assistant control, two pump protocols

Both supported families appear as a Home Assistant fan, while the integration translates Home Assistant commands to the native control model used by the pump.

iSaver Power 1100

  • Actual pump speed in rpm
  • Physical range: 1200–2900 rpm
  • 100 rpm command grid
  • Home Assistant presets: Max, Day/Jour, Eco, Night/Nuit, Custom/Perso
  • Validated persistent OFF command: value 1

DM15 / INVERsilence

  • Actual running capacity from register 2003
  • Native operating range: 30–100%
  • Integer percentage control through register 3001
  • Modbus function 03 for reads and 10 for writes
  • Validated OFF command: register 3001 = 0

Automatic Aquagem protocol detection

Setup starts with safe read-only probes. A simple TCP connection or generic Modbus answer is not accepted as a match.

Probe the iSaver signature

The integration validates the proprietary C3 frame structure and CRC.

Probe Aquagem Modbus

It checks holding registers 2001–2004, first at address 0xAA and then the Aquagem address range if required.

Store the detected profile

Once identified, the protocol and Modbus unit are kept in the config entry so polling uses only the correct backend.

The RS485 baud rate is configured in the gateway itself. Use 1200 baud for the validated iSaver C3/D0 profile and 9600 baud for the validated Aquagem Modbus profile.

RS485-to-TCP gateway settings

A transparent gateway is required. The integration sends complete RTU/proprietary serial frames through the TCP stream.

Do not enable a gateway "Modbus TCP to RTU" conversion mode. Aquagem Pump already builds the serial frames expected by the pump.

Status, alarms and diagnostics

The integration exposes a common connection state, alarm state and raw fault word, plus protocol-specific sensors. Unknown values remain raw instead of being assigned an unverified meaning.
