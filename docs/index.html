Home Assistant control for Aquagem DM15, INVERsilence and iSaver

Both supported families appear as a Home Assistant fan, while the integration translates commands to the native control model used by the pump.

iSaver Power 1100

  • Actual pump speed in rpm
  • Physical range: 1200–2900 rpm
  • 100 rpm command grid
  • Home Assistant presets: Max, Day, Eco, Night and Custom
  • Validated persistent OFF command: value 1

DM15 / INVERsilence

  • Actual running capacity from register 2003
  • Native operating range: 30–100%
  • 5% capacity steps: 30, 35, 40 ... 100%
  • Unsupported values are rounded down to the lower 5% step
  • Electrical power from register 2004 in watts
  • Modbus function 03 for reads and 10 for writes
  • Validated OFF command: register 3001 = 0

Automatic Aquagem RS485 protocol detection

Setup starts with safe read-only probes. A simple TCP connection or generic Modbus answer is not accepted as a match.

Probe the iSaver signature

The integration validates the proprietary C3 frame structure and CRC.

Probe Aquagem Modbus

It checks holding registers 2001–2004, first at address 0xAA and then the documented Aquagem address range if required.

Store the detected profile

Once identified, the protocol and Modbus unit are saved so normal polling uses only the correct backend.

Use 1200 baud for the validated iSaver C3/D0 profile and 9600 baud for the validated DM15 / INVERsilence Modbus profile.

FAQ

Aquagem Home Assistant FAQ

Can I control an Aquagem DM15 or INVERsilence from Home Assistant?

Yes. The validated Modbus profile provides ON/OFF and 30–100% capacity control through a transparent RS485-to-TCP gateway. Version 0.3.4 uses the pump's real 5% capacity grid.

Does the integration use the Aquagem cloud?

No. The integration communicates locally between Home Assistant, the RS485 gateway and the pump.

What does Modbus register 2004 report?

On the validated DM15 / INVERsilence profile, register 2004 reports electrical power in watts. Aquagem Pump exposes it with Home Assistant's power device class and measurement state class.

Why can the physical pump panel stop responding during bus control?

Some Aquagem pump controllers prioritize remote/bus operation while Modbus commands are active. This behavior has also been observed on other Aquagem inverter products and is being documented separately from Home Assistant control.

Which languages are available?

The integration includes English, French and Spanish display translations. Generated entity IDs stay based on English names for stable automations and dashboards.
