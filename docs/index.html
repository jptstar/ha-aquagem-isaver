USB-RS485 or RS485/TCP

Choose the transport that fits your installation. The protocol layer remains the same.

Direct USB-RS485

  • Home Assistant 2026.9 or newer
  • Stable /dev/serial/by-id/... path recommended
  • DM15 / Modbus: 9600-8-N-1
  • iSaver: 1200-8-N-1
  • Uses Home Assistant's native serialx stack through the built-in USB dependency

Transparent RS485/TCP

  • TCP Server mode, commonly port 502
  • 8 data bits, no parity, 1 stop bit
  • No Modbus TCP-to-RTU conversion
  • Automatic read-only protocol detection available
  • Specific Modbus slave address can be selected for shared buses

Several Modbus pumps on the same physical bus

Aquagem Pump 0.4.0 identifies each Modbus device by its bus endpoint and slave address. Each pump remains a separate Home Assistant device while sharing the same RS485 line safely.

Address each pump

For example 0xAA, 0xAB and 0xAC behind one USB adapter or TCP gateway.

Queue transactions FIFO

A shared bus manager gives the line to waiting transactions in arrival order.

Keep frames atomic

Each request and its response complete before the next addressed pump can use the bus.

One line, one serial configuration.Do not mix the 1200-baud iSaver profile and the 9600-baud Modbus profile on the same wired RS485 bus.

FAQ

Aquagem Home Assistant FAQ

Can I control an Aquagem DM15 or INVERsilence from Home Assistant?

Yes. The validated Modbus profile provides ON/OFF and 30–100% capacity control in 5% steps, plus power and diagnostics.

Can I use a WaveShare RS485-to-Ethernet gateway?

Yes. A WaveShare transparent TCP Server configuration has been validated on a real iSaver Power 1100. The dedicated setup guide includes the screenshot and the corresponding DM15 / INVERsilence baud settings.

Can several pumps use the same RS485 adapter?

Yes for addressed Modbus pumps. Version 0.4.0 supports several slave addresses on one USB-RS485 adapter or transparent RS485/TCP gateway and serializes transactions through a shared FIFO bus manager.

Does the integration require the Aquagem cloud?

No. Communication remains local between Home Assistant and the RS485 connection.

Does it support direct USB-RS485?

Yes. Home Assistant 2026.9+ can use a direct serial adapter through its native serial stack. The integration explicitly opens the supported serial profiles as 8-N-1.

What does Modbus register 2004 report?

On the validated DM15 / INVERsilence profile, register 2004 reports electrical power in watts and is exposed as a Home Assistant power sensor.

Which languages are available?

English, French and Spanish display translations are included.
