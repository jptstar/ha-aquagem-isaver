Validated DM15 Modbus profile

The integration uses the pump's Modbus RTU 03/10 profile at 9600-8-N-1. Compatibility is based on the validated register behavior rather than only the commercial model name.

Several DM15 pumps on one RS485 bus

Aquagem Pump 0.4.0 identifies each Modbus device by bus endpoint plus slave address. Several DM15 pumps can therefore share one USB-RS485 adapter or one transparent RS485/TCP gateway.

RS485 bus
  ├── DM15 0xAA
  ├── DM15 0xAB
  └── DM15 0xAC

The shared FIFO bus manager serializes complete request/response transactions so frames from separate Home Assistant entries cannot interleave.
