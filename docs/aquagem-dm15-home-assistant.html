Return to local control

Aquagem Pump 0.4.3 applies the same generic post-command quiet-window mechanism to supported DM15 / Aquagem Modbus pumps. It is enabled by default and uses 70 seconds on new installations, adjustable from 50 to 180 seconds.

Several DM15 pumps on one RS485 bus

Several Modbus slave addresses can share one USB-RS485 adapter or transparent RS485/TCP gateway. A shared FIFO bus manager serializes complete request/response transactions.
