Who contributed to what

Credits are intentionally specific: each person is listed only for the hardware validation or project input they directly contributed.

DM15 / INVERsilence real-hardware validationAntonio Garcia

Independently validated the Aquagem DM15 / INVERsilence Modbus profile on real hardware. His testing confirmed the core Modbus read map, the native 5% capacity-control grid, register 2004 as electrical power in watts, and the guarded write / OFF control sequence used by the integration.
