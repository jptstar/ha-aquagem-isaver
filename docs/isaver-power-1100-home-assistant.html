Measured return-to-local-control behavior

Real-hardware testing isolated the iSaver watchdog from the WaveShare transport.

D0 command → remote priority active for ~60 s → C3 read inside that window prolongs remote priority → true silent interval lets the panel regain control → C3 after local return does NOT restore the old D0 setpoint
Aquagem Pump 0.4.3 enables Return to local control by default and uses a 70-second protected silence on new installations. The delay is configurable from 50 to 180 seconds.

WaveShare result

Tests with the TCP socket closed and with the TCP socket left open but completely idle both returned the pump to its manual setpoint after the watchdog. This strongly indicates that the important condition is RS485/protocol silence, not whether the WaveShare TCP session remains open.
